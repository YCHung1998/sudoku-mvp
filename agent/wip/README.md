# Work-in-progress notes

One Markdown doc per unfinished / in-progress item, for handing off
state across sessions (nothing here is merged to main yet). Same idea
as `agent/tasks/`, but **no commit field**.

Add a row to the table below (newest first) and a matching file named
`NNNN-short-slug.md`. When an item is finished and merged, move it to
`agent/tasks/` and record the commit/PR hash there.

## Template

```markdown
# <title>

- **Date:** YYYY-MM-DD
- **Status:** in-progress | blocked | paused
- **Files:** key/files/touched (note which are unmerged)

## Goal
What this work is trying to achieve.

## Done
What is already finished.

## Remaining
What is left, and any blockers / open decisions.

## Notes
Context needed to resume cold (paths, commands, gotchas).
```
