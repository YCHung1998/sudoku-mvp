# 網頁版數獨遊戲

這是一個用純 HTML/CSS/JavaScript 實現的網頁版數獨遊戲，支援多個難度等級和互動功能。

## 功能特性

- **9x9 數獨盤面** - 自動生成完整合法的數獨題目
- **三個難度等級**
  - 初階：挖空約 35 格
  - 中階：挖空約 45 格
  - 高階：挖空約 55 格
- **互動填數**
  - 點擊空格選中，使用數字鍵盤或實體鍵盤輸入（1-9）
  - 預填的題目格無法修改，樣式以灰色區分
- **內置數字鍵盤** - 1-9 數字按鈕 + 清除鍵
- **實時反饋**
  - 填錯時格子變紅色提示
  - 顯示已填入數、錯誤數、完成進度
- **解答查看** - 「顯示解答」按鈕可切換查看標準答案，關閉後恢復使用者目前的作答狀態
- **新遊戲** - 隨時開始新的遊戲

## 使用方式

### 直接開啟
在瀏覽器中打開 `index.html` 檔案即可開始遊玩。

### GitHub Pages
如果將此項目上傳至 GitHub，可在 Repository Settings 中啟用 GitHub Pages，即可線上遊玩。

## 技術實現

- **純 HTML/CSS/JavaScript** - 無任何外部依賴或框架
- **數獨生成演算法** - 使用回溯法生成完整合法的數獨盤面
- **隨機挖空** - 根據難度隨機移除相應數量的格子
- **即時驗證** - 對比使用者輸入與標準答案，實時提示錯誤
- **響應式設計** - 支援桌面和行動設備瀏覽

## 遊玩提示

1. 選擇難度等級並點擊「新遊戲」開始
2. 點擊空白格子選中，使用數字鍵盤或鍵盤輸入 1-9
3. 按 Backspace 或點擊「清除」移除錯誤的數字
4. 隨時可點擊「顯示解答」查看正確答案
5. 進度條和統計資訊在右下方實時更新
